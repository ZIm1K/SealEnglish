## Що потрібно від власника

1. **ElevenLabs.** У кабінеті ElevenLabs → Developers → API Keys → ключ ферми → увімкнути
   `User → Read`.
2. **Дозволити деплой двох Edge Functions** (`google-oauth` з новим scope і `farm-kick`) або
   задеплоїти їх самому. Без цього не запрацюють п. 5, 7, 8 і 14.
3. **Перепідключити Google** після деплою `google-oauth`: кабінет → Налаштування → Інтеграції →
   підключити Google ще раз і погодитись на доступ до Диска.
4. **Ключ для `farm-kick`.** Створити ключ сервісного акаунта й покласти його у Vault:

   ```bash
   gcloud iam service-accounts keys create seal-farm-kick.json --iam-account seal-farm-scheduler@bond-bot-494410.iam.gserviceaccount.com --project bond-bot-494410
   ```

   ```bash
   npm run farm -- kick-setup --key seal-farm-kick.json
   ```

5. **Перенесення відео** після п. 3:

   ```bash
   npm run farm -- drive-migrate
   ```

   ```bash
   npm run farm -- storage-cleanup --yes
   ```

   Друга команда безповоротно видаляє відео із Supabase; без `--yes` вона лише показує перелік.

## Лишилось зробити

- **Порівняння «до / після»** для трьох змін (п. 2): скорочена бренд-біблія для кожного типу
  виклику, ідеї на effort medium, редактор повертає лише правки. Кожна зміна — за налаштуванням,
  вимкнена за замовчуванням; порівняння на трьох однакових ідеях, ≈ $1 через Batch API;
  вмикається лише після «ок» власника.
- Після того як `farm-kick` запрацює: тик `work` зробити погодинним і оновити в кабінеті текст
  «протягом ~30 хвилин».
- Тести: зараз є лише перевірка типів.
