## Що потрібно від власника

1. **ElevenLabs.** У кабінеті ElevenLabs → Developers → API Keys → ключ ферми → увімкнути
   `User → Read`.
2. **Перепідключити Google**: кабінет → Налаштування → Інтеграції → підключити Google ще раз і
   погодитись на доступ до Диска (функція `google-oauth` уже просить цей дозвіл).
3. **Ключ для `farm-kick`.** Створити ключ сервісного акаунта й покласти його у Vault:

   ```bash
   gcloud iam service-accounts keys create seal-farm-kick.json --iam-account seal-farm-scheduler@bond-bot-494410.iam.gserviceaccount.com --project bond-bot-494410
   ```

   ```bash
   npm run farm -- kick-setup --key seal-farm-kick.json
   ```

4. **Перенесення відео** після п. 2:

   ```bash
   npm run farm -- drive-migrate
   ```

   ```bash
   npm run farm -- storage-cleanup --yes
   ```

   Друга команда безповоротно видаляє відео із Supabase; без `--yes` вона лише показує перелік.

## Лишилось зробити

- **Ідеї на effort medium** (п. 2). Контрольний прогін на вході сьогоднішнього пакета:
  high — $0.096, medium — $0.076, тобто ≈ $0.02 з пакета (≈ $0.30 на місяць). Обидва списки ідей —
  у `out/compare-ideate-effort.md`. Увімкнути: `"ideate_effort": "medium"` в
  `app_settings.content_farm` (потрібен ще один деплой — налаштування з'явилось після останнього).
- **Скорочена бренд-біблія і «редактор повертає лише правки»** (п. 2). Оцінки робились до Batch API;
  тепер, коли тексти коштують удвічі менше, перша дає ≈ $0.2 на місяць, друга ≈ $0.45, а саме
  порівняння коштує ≈ $0.5 і додає складний код у редактор. Рекомендую не робити; остаточне слово
  за власником.
- Після підключення Диска: зняти з паузи розклад резервної копії
  (`gcloud scheduler jobs resume seal-farm-backup --location europe-west1 --project bond-bot-494410`).
- Після того як `farm-kick` запрацює: тик `work` зробити погодинним і оновити в кабінеті текст
  «протягом ~30 хвилин».
- Тести: зараз є лише перевірка типів.
