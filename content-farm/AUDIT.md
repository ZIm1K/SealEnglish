Стан на 4 жовтня 2026. Описує, що де і як працює, скільки коштує кожен крок, що виправлено

## 1. Що це

Конвеєр, який раз на 2 дні готує **пакет із 5 матеріалів** (TikTok-історія, навчальне відео для
Stories, пости для Threads, Telegram та Instagram), чекає на затвердження власника в кабінеті,
а потім виробляє медіа й надсилає результат у Telegram.

```
Cloud Scheduler ──▶ Cloud Run Job «seal-farm» ──▶ Supabase (таблиці, сховище, налаштування)
   pack  09:00 кожні 2 дні        │                      ▲
   work  кожні 30 хв 08–23:30     │                      │ кабінет /app/content/
                                  ▼                      │ (затвердити / переписати / відхилити)
              Claude · ElevenLabs · Gemini · Groq ──▶ Telegram-бот (прев'ю адмінам)
```

| Складова | Де | Що робить |
|---|---|---|
| Cloud Run Job `seal-farm` | Google Cloud, проєкт `bond-bot-494410`, `europe-west1`, 2 vCPU / 4 ГБ, тайм-аут 60 хв, без повторів | Контейнер з фермою ([Dockerfile](Dockerfile)); команда за замовчуванням — `work` |
| Scheduler `seal-farm-pack` | `0 9 */2 * *`, Europe/Kyiv | Запускає job з аргументом `pack` |
| Scheduler `seal-farm-work` | `*/30 8-23 * * *`, Europe/Kyiv | Запускає job без аргументів (`work`) |
| Supabase `nivxzpsstjphxkodhjzu` | таблиці `content_runs`, `content_ideas`, `content_items`, `content_posts`; бакет `content`; `app_settings` | Дані, медіа, кеш, налаштування |
| Кабінет | сайт, `/app/content/` ([page.tsx](../src/app/app/content/page.tsx), [content-editor.tsx](../src/components/app/content-editor.tsx)) | Редагування й затвердження |
| Деплой | [scripts/deploy-cloud.sh](scripts/deploy-cloud.sh) | Збирає образ з робочої теки, оновлює job і розклади |

`git push` ферму **не** деплоїть: хмара оновлюється лише скриптом деплою, і він бере файли
з робочої теки разом з усіма незакоміченими змінами.

### 2.2 Виробництво (`work`, кожні 30 хв)

1. **Переписування.** Матеріали зі статусом `script_rewrite` переписуються за коментарем власника
   (`rewriteWithNote()`), повертаються в `script`.
2. **Виробництво.** Матеріали зі статусом `approved` забираються атомарно (`claimItem`: `approved → rendering`).

Для **історії** (`storyMedia()`):

| Крок | Як | Сервіс |
|---|---|---|
| Озвучка кожної репліки окремим голосом персонажа, з таймінгами слів | [src/media/tts.ts](src/media/tts.ts), [eleven.ts](src/media/eleven.ts) | ElevenLabs `eleven_v4`; запасні — Gemini TTS, Edge, OpenAI |
| Таймінги слів, якщо рушій їх не дав | [src/media/align.ts](src/media/align.ts) | Groq Whisper |
| Фон кожної локації (3 паралельно) | [src/media/images.ts](src/media/images.ts), [gemini.ts](src/media/gemini.ts) | Gemini 3.1 Flash Lite Image, 1K, 9:16 |
| Де голова персонажа фону (для камери й бульбашок) | [src/media/locate.ts](src/media/locate.ts) | Claude Sonnet 5.5 з картинкою |
| Музика й звуки | [src/media/music.ts](src/media/music.ts), [sfx.ts](src/media/sfx.ts) | генеруються кодом (тека `assets/music/` порожня) |
| Тайминг кадрів | [src/layout.ts](src/layout.ts) | — |
| Рендер 1080×1920, H.264 crf 17 + обкладинка | [src/render.ts](src/render.ts), [remotion/Story.tsx](remotion/Story.tsx) | Remotion (headless Chrome) |
| Завантаження в бакет, статус `review`, відео в Telegram | [src/store.ts](src/store.ts), [src/notify.ts](src/notify.ts) | — |

**Навчальне відео** (`eduMedia()`): усі репліки озвучує Сілі; один фон на все відео плюс до двох
картинок сцен; шаблон [remotion/Short.tsx](remotion/Short.tsx).

плюс картка з текстом ([remotion/IgCard.tsx](remotion/IgCard.tsx)).

## 3. Кеш і чому повтор майже безкоштовний

[src/cache.ts](src/cache.ts) зберігає в бакеті `content/cache/` три види результатів, ключ — хеш
того, що їх породило:

| Що | Ключ | Наслідок |
|---|---|---|
| Репліка (аудіо + таймінги) | провайдер, модель, голос, темп, текст, манера | після правки однієї репліки переозвучується лише вона |
| Картинка | провайдер, моделі, промпт, стиль, формат | той самий фон не оплачується двічі |
| Позиція голови | хеш самої картинки + бік | для закешованого фону пошук голови безкоштовний |

Перерендер після збою коштує $0, якщо тексти й промпти не змінювались (перевірено 4 жовтня).

## 7. Здешевлення

### Застосовано

| Зміна | Економія | Чому якість не страждає |
|---|---|---|
| Прибрано кеш-мітки з разових викликів Claude | ≈ $0.02 на історію, ≈ $0.06 на пакет | Виміряно: `cache_read` дорівнював 0 між усіма викликами (у кожного своя схема відповіді, а вона входить у кешований префікс), тож мітка лише додавала 25% до ціни входу. Сам запит не змінився |
| Банк історій на 4 дні | ≈ $0.14 на двох пакетах із трьох | Одне дослідження дає 10–12 історій, пакет бере 1–2; уже використані відсіюються за назвою. Вимикається: `story_research_days: 0` |
| Пошук голови на Sonnet 5.5 замість Opus 5.5 | ≈ $0.005 на фон | На трьох локаціях координати x / y / верх голови збіглися з Opus у межах 0.03 кадру; поле `size`, де розбіжність більша, ніде не читається |
| Тексти для Threads і Telegram прибрано зі сценаріїв відео | ≈ $0.03 на сценарій (оцінка за довжиною полів) | На відео не впливає; у пакеті вже є окремі пости для цих мереж. **Це зміна поведінки**: у кабінеті під відео ці два поля тепер порожні. Повернути: `video_cross_posts: true` |
| Пошук, що працює | — | Ті самі ≈ $0.25 тепер купують справжні тренди й джерела |

Разом ≈ $0.07 на історію (≈ 17%) і ≈ $0.23 на пакет. Перші три рядки виміряно на токенах
реальних викликів, четвертий — оцінка.

### Не застосовано — потрібне ваше рішення

| Важіль | Економія | Ціна |
|---|---|---|
| Batch API для текстів пакета | −50% тексту, ≈ $0.30 на пакет | Пакет приходитиме на години пізніше; потрібен новий стан «чекаю на пакет» між запусками `work` |
| Скоротити бренд-біблію для кожного типу виклику | ≈ $0.04 на пакет | Біблія — 5.3 тис. токенів у кожному з 7 викликів. Зміна промптів: результат треба переглянути очима |
| `effort` ідей: high → medium | до ≈ $0.05 на пакет | Без набору еталонних оцінок не видно, чи ідеї не погіршаться |
| Менше локацій в історіях-фактах (зараз 4–6) | $0.03–0.07 на історію | Менше зміни картинки |
| Редактор повертає лише змінені поля | ≈ $0.03 на відео | Складніша логіка, ризик зламати правку сюжету |
| Рідше запускати `work` або запускати за подією затвердження | хмарний час | 32 запуски на день, порожній триває ≈ 45 с (здебільшого старт контейнера) |

### Перевірено й відкинуто

- **Спільний кешований префікс (бренд-біблія першою).** Виміряно: не читається між викликами
  з різною схемою відповіді. Порядок промптів повернуто до початкового.
- **Кешування всередині пошукового циклу.** Модель робить усі пошуки одним колом, тож запис
  у кеш ніхто не читає — виходило трохи дорожче.
- **Дешевший рендер.** Ферма за нього не платить провайдерам ШІ, а якість кодування чіпати не варто.

## 8. Ризики, які лишились

| Ризик | Деталі |
|---|---|
| **Сховище росте на ≈ 30 МБ за відео** | У бакеті вже 467 МБ за три дні; 5 рендерів (115 МБ) — застарілі версії, на які ніхто не посилається. Старі версії ніколи не видаляються. Якщо проєкт на безкоштовному тарифі Supabase, ліміт близько |
| Баланс ElevenLabs не видно | Ключ не має права читати підписку (HTTP 401). Якщо кредити закінчаться, репліки озвучить запасний голос Gemini; тепер про це буде позначка в повідомленні |
| Баланс Gemini | 3 жовтня передплачені кредити закінчились, два пости впали в `failed` і досі там |
| Якість не має автоматичної перевірки | Немає набору еталонних сценаріїв; єдиний контроль — ваш перегляд. Тому важелі з розділу 7, що міняють промпти чи моделі, не застосовано |
| Редактор-хуманізатор падає мовчки | При помилці повертається чернетка без редагування, без позначки |
| Супровідні тексти після ручної правки | Правка реплік у кабінеті не оновлює підписи для TikTok та Instagram |
| Розклад `*/2` за числом місяця | Після 31-го наступний пакет виходить 1-го — два дні поспіль |
| Збій дослідження зупиняє весь пакет | Помилка API в `research()` не перехоплюється; повторів у job немає (`max-retries 0`) |
| Кеш у бакеті не чиститься | Зараз 41 файл, 4.5 МБ — некритично |
| Бакет `content` публічний | Так задумано (Instagram і Threads забирають медіа за посиланням), але й неопубліковані відео та картинки відкриваються за прямим URL, якщо знати шлях |
| Кабінет показує порожні поля Threads і Telegram під відео | Наслідок `video_cross_posts: false`; прибрати поля — правка сайту |
| Remotion | Безкоштовний до 3 працівників у компанії |
| Автопостинг (етап 2) | Не збудований; таблиця `content_posts` порожня |

## 9. Діагностика

| Що подивитись | Де |
|---|---|
| Журнал запуску й звіти трендів | `content_runs.log`, `content_runs.web_report` |
| Вартість і токени кожного кроку | `content_items.cost_breakdown` (`what`, `usd`, `tokens`) |
| Причина збою матеріалу | `content_items.review_note`, також у кабінеті й Telegram |
| Журнал хмарного запуску | `gcloud logging read 'resource.type="cloud_run_job" AND resource.labels.job_name="seal-farm"' --project bond-bot-494410` |
| Банк історій | `app_settings`, ключ `content_farm_story_bank` |
| Перевірка типів | `npm run typecheck` |

Ознака, що пошук знову не працює: у повідомленні про пакет і в журналі запуску є рядок
«⚠ веб-пошук не дав результатів».
