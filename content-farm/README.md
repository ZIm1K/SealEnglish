# Контент-ферма Seal English

Автоматичний конвеєр: **зріз трендів → аналіз ШІ → ідеї → сценарії → озвучка/картинки → рендер відео → черга на перевірку**.
Працює в Google Cloud Run (безкоштовний ліміт), ПК не потрібен. Раз на 2 дні готує пакет контенту на затвердження в кабінеті; після затвердження генерує медіа й надсилає в Telegram.

## Де це працює

Повністю в хмарі, ПК не потрібен:
- **Google Cloud Run Job `seal-farm`** (проєкт `bond-bot-494410`, `europe-west1`) — контейнер з фермою (Dockerfile), 2 vCPU / 4 ГБ.
- **Cloud Scheduler**: `seal-farm-pack` — пакет раз на 2 дні о 09:00 (Київ); `seal-farm-work` — кожні 30 хв (08:00–23:30)
  виробляє затверджені матеріали (порожній запуск триває секунди).
- **Supabase** — дані, сховище медіа, кабінет.
- Оновити після змін у коді: `bash content-farm/scripts/deploy-cloud.sh` (ключі беруться з `content-farm/.env`).
- Ручний запуск: `gcloud run jobs execute seal-farm --region europe-west1 --args=pack` (або `custom --topic "…"`).

## Пакет раз на 2 дні → затвердження в кабінеті

Кабінет → **«Контент-ферма»** (`/app/content/`), пакет із 5 матеріалів:
1. 🎵 TikTok — історія-сценка з Сілі (голоси ElevenLabs, фони Gemini, рендер).
2. 📲 Stories — навчальне відео (квіз / «не кажи так» / список).
3. 🧵 Threads — лише текст.
4. ✈️ Telegram — текст + промпт → згенерована картинка.
5. 📸 Instagram — картка 4:5 (фото + великий хук + англ. фраза) і допис під фото.

Редагуйте → **Затвердити** (хмара згенерує медіа протягом ~30 хв і надішле в Telegram) · **Переписати з коментарем** · **Відхилити**.

## Як це працює

**Контент-мікс:** 70% — вірусні історії для всіх (TikTok/Reels), 30% — навчальні рубрики (квізи, «не кажи так» — для Stories/TG).

| Етап | Що робить | Чим | Вартість |
|---|---|---|---|
| 1. Зріз трендів | Google Trends UA/US, YouTube UA (опційно), пошук трендів TikTok/Reels/Threads + окремий пошук **перевірених історій з джерелами** | Claude Sonnet 5.5 + web search | ≈ $0.2–0.4 / день |
| 2. Ідеї | Тренд → історія/рубрика, оцінки вірусності й «цікаво будь-кому» | Claude Opus 5.5 | ≈ $0.05 |
| 3. Сценарій | Історія по кадрах: оповідач, **Сілі як дійова особа**, герої з прямою мовою (англомовні — англійською), емоція кожної репліки | Claude Opus 5.5 | ≈ $0.10 |
| 4. Хуманізація | Окремий прохід-редактор прибирає ШІ-штампи з усіх текстів (стоп-лист у `src/brand.ts` → `HUMAN_VOICE`) | Claude | ≈ $0.05 |
| 5. Озвучка | **Окремий голос на кожного персонажа** + інструкція емоції; таймінги слів для субтитрів — Whisper | Gemini TTS (запасний — Edge) | ≈ $0.01 |
| 6. Кадри | Кадри з Сілі — за референсом його 3D-рендерів (він завжди «той самий»), сцени — дешевша модель; фон змінюється за сюжетом | Gemini 3.1 Flash Image / Lite | ≈ $0.40 (4×$0.067 + 4×$0.034) |
| 7. Музика | Свої треки з `assets/music/` або згенеровані (ліцензійно чисті) | локально | $0 |
| 8. Рендер і черга | Remotion → Supabase Storage → прев'ю адмінам у Telegram | ПК + Supabase | $0 |

**Разом ≈ $0.55–0.65 за відео-історію** (жорсткий ліміт $1: дорожчі кроки пропускаються), навчальний ролик ≈ $0.15, текстовий пост ≈ $0.03–0.06.

## Запуск

```bash
cd content-farm
npm ci
npm run demo                     # тестовий ролик без ключів → out/demo.mp4
npm run farm -- daily            # повний цикл
npm run farm -- custom --topic "Хелловін: як не облажатися з trick or treat"
npm run farm -- scan             # лише ідеї (видно в content_ideas)
npm run farm -- produce --videos 1
npm run studio                   # візуальний редактор шаблону (Remotion Studio)
```

Локально потрібен лише `SUPABASE_SERVICE_ROLE_KEY` у `content-farm/.env` (див. `.env.example`) — решта ключів береться з Vault.

## Що потрібно налаштувати один раз

1. Скопіюйте `.env.example` → `.env` і вставте `SUPABASE_SERVICE_ROLE_KEY` (Supabase → Project Settings → API → service_role).
   Цей ключ дає повний доступ до бази — файл `.env` у git не потрапляє, нікому його не пересилайте.
2. **Ключ Gemini** (голоси + кадри з Сілі) — https://aistudio.google.com/apikey, з увімкненим білінгом
   (генерація зображень на безкоштовному тарифі недоступна). Додайте в `content-farm/.env`: `GEMINI_API_KEY=...`
   Без нього: голос — безкоштовний Edge (звучить штучніше), кадри — фірмовий фон із Сілі.
3. *(необов'язково)* `youtube_api_key` тим самим способом — додає YouTube-тренди.
4. *(необов'язково)* фонова музика: покладіть 5–10 треків у `assets/music/` з префіксом настрою —
   `upbeat-1.mp3`, `chill-1.mp3`, `funny-1.mp3`, `suspense-1.mp3`. Беріть лише ліцензійно чисті (YouTube Audio Library, Pixabay Music).
   Трендові звуки TikTok/IG через API додати не можна — їх, за бажанням, підставляють вручну при публікації.

## Налаштування без деплою

`app_settings.content_farm` (JSON) перекриває значення з `src/env.ts`, напр.:

```json
{ "videos_per_run": 3, "texts_per_run": 2, "model": "claude-sonnet-5-5", "ai_images_per_video": 1, "max_usd_per_video": 0.5 }
```
